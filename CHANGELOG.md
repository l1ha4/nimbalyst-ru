# Changelog

## 1.2.0 — 2026-11-11

- 187 вручную переведённых описаний навыков, команд и встроенных расширений, включая все 11 поставляемых `SKILL.md`.
- Перевод при отображении в меню команд, подсказках, карточках расширений и их подробном описании; инструкции навыков и данные команд сохраняются.
- Русские заголовки групп команд и навыков, подписи быстрых действий, даты «Сегодня / Вчера» и дополнительные обучающие подсказки.
- Установка поверх предыдущего русификатора одной кнопкой: предварительная сборка из оригиналов, сохранение резервных копий, откат при ошибке и восстановление прерванного обновления.
- 23 автоматизированных теста, включая отображение каждого из 187 описаний и сохранение исходных команд и запросов.

## 1.1.0 — 2026-11-11

- Автономный установщик Windows x64: один EXE, русский интерфейс, встроенный Node.js 24.22.2.
- Установка, удаление, диагностика, восстановление, выбор папки и явный пробный режим для новых версий.
- Отчёты графического установщика сохраняются вне временного пакета.
- Открытый исходный код сборки, проверка SHA-256 и подписи официального Node.js.
- Инструкция на русском и английском, шаблоны Issues и тесты в GitHub Actions.

## 1.0.0 — 2026-11-11

- Первый пакет русификации Nimbalyst 0.83.0: словарь, ручные исправления, AST-преобразование интерфейса.
- Резервные копии, проверка совместимости, побайтный откат и восстановление после прерывания.
- 14 тестов преобразования и установки.
