Неофициальный устанавливаемый русификатор Nimbalyst для Windows: Russian language pack, localization mod, перевод интерфейса на русский язык. Версия мода: **1.2.0**. Проверенная версия приложения: **0.83.0**. Проект не связан с разработчиками Nimbalyst и не является официальной локализацией.

## Установка

1. Скачайте **[Nimbalyst-RU-Setup-1.2.0.exe](https://github.com/l1ha4/nimbalyst-ru/releases/download/v1.2.0/Nimbalyst-RU-Setup-1.2.0.exe)**.
2. Полностью закройте Nimbalyst, включая значок в трее.
3. Откройте скачанный файл и нажмите **«Установить»**. Папка приложения определяется автоматически; при необходимости выберите её вручную.
4. Подтвердите запрос администратора Windows, если Nimbalyst находится в защищённой папке.
5. После сообщения об успешной установке запустите Nimbalyst обычным способом.

**Один EXE, без распаковки и отдельной установки Node.js.** Установщик работает без интернета; Node.js 24.22.2 включён в пакет. Целевая система — Windows 10/11 x64 со штатным .NET Framework 4.8. Установщик не подписан сертификатом издателя; исходный код и SHA-256 файлов опубликованы в релизе.

В этом же окне доступны **«Удалить перевод»**, **«Диагностика»**, **«Восстановить»** и **«Открыть отчёты»**. Графический установщик сохраняет отчёты в `%LOCALAPPDATA%\Nimbalyst-RU\reports`. Распакованные служебные файлы удаляются при закрытии; резервные копии остаются для отката.

## Альтернатива: установка из исходного ZIP

1. Распакуйте весь архив в отдельную папку. Не запускайте файлы прямо из ZIP.
2. Полностью закройте Nimbalyst, включая значок в трее.
3. Запустите `Install.cmd`. Установщик найдёт Nimbalyst, проверит совместимость, создаст резервные копии и установит перевод.
4. Если приложение находится в `C:\Program Files`, Windows может запросить права администратора. Это нужно для замены файлов установленной программы.
5. Откройте Nimbalyst обычным способом.

Для исходного ZIP требуется отдельно установленный **Node.js 20 или новее**; рекомендуется [поддерживаемая LTS-версия](https://nodejs.org/). Установщик не скачивает зависимости и не обращается к сервисам перевода. Acorn включён в пакет. Для EXE отдельный Node.js не нужен.

Если найдено несколько установок или используется нестандартная папка:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Action install -AppDir "D:\Apps\Nimbalyst"
```

Параметр `ExecutionPolicy Bypass` действует только на этот запуск PowerShell и не меняет системную политику.

## После обновления Nimbalyst

**Обновление самого русификатора:** скачайте новый EXE и нажмите «Установить». Начиная с 1.2.0 он распознаёт старую версию мода, сначала собирает новый перевод из сохранённых оригиналов и только после проверок заменяет файлы. Ручное удаление старого мода не требуется; первоначальные резервные копии сохраняются.

Повторно откройте EXE и нажмите **«Установить»** (или запустите `Install.cmd` в исходном пакете). Перевод не восстанавливается автоматически: фоновых задач, служб и отключения автообновлений нет.

Если версия ещё не проверена, обычный установщик сформирует отчёт и остановится. Флажок **«Пробная установка на новой версии»** в EXE или `Install-After-Update.cmd` позволяют явно попробовать установку после автоматических проверок. Проверки обязательны и в этом режиме: приложение должно иметь ожидаемую структуру, код должен разбираться без ошибок, а совпадение со словарём — быть достаточным. Пробный режим не гарантирует совместимость с будущими выпусками.

Для каждой новой версии создаётся **собственная** резервная копия. Удаление мода восстанавливает именно эту версию, а не предыдущий выпуск приложения.

Если после обновления появились английские надписи или ошибка:

1. Нажмите **«Диагностика» → «Открыть отчёты»** в EXE или запустите `Diagnose.cmd`.
2. Создайте [Issue](https://github.com/l1ha4/nimbalyst-ru/issues/new/choose) с диагностическими JSON, версией приложения и описанием проблемы. Если проблема визуальная, полезен снимок экрана без личных данных.
3. При необходимости верните оригинал кнопкой **«Удалить перевод»** или через `Uninstall.cmd`.

Диагностические JSON содержат версии, хеши, относительные пути файлов приложения и статические строки его интерфейса. Документы, переписки, настройки аккаунтов, API-ключи и журналы Nimbalyst они не читают. Файл `last-operation.log` может содержать локальные пути; его передача необязательна.

## Удаление и восстановление

`Uninstall.cmd` восстанавливает исходные файлы побайтно, с проверкой SHA-256. Если файл успело изменить обновление или другой мод, установщик откажется перезаписывать его старой копией.

`Recover.cmd` предназначен для прерванной установки: сначала проверяет все файлы, резервные копии и временные файлы, затем восстанавливает оригинал. Не используйте его для отката обновления приложения.

Резервные копии и журнал находятся вне папки Nimbalyst:

```text
%LOCALAPPDATA%\Nimbalyst-RU\<идентификатор установки>\
    installation.json
    backups\<версия>-<хеш>\
```

Поэтому можно перемещать папку русификатора и распаковывать следующую версию пакета в другое место. Не удаляйте `%LOCALAPPDATA%\Nimbalyst-RU`, пока хотите иметь возможность отката. Обычно копия требует около 120–160 МБ на версию; при крупных обновлениях размер может измениться. Сбойные стадии сборки могут занимать дополнительное место.

## Что переводится

- Меню, кнопки, окна, подсказки, настройки, сеансы, трекеры и редакторы в поддерживаемых контекстах.
- Интерфейс встроенных расширений, поставляемых вместе с этой версией приложения.
- Для Excalidraw включается его собственная поставляемая русская локализация.
- Описания 11 встроенных навыков, команд и расширений: 187 переведённых описаний и пунктов возможностей. Перевод виден в меню команд, всплывающих подсказках и карточках расширений.
- Заголовки групп команд и навыков, подписи быстрых действий на стартовом экране, даты «Сегодня / Вчера».

Перевод подготовлен из статических строк установленной сборки. Для массового черновика использован машинный перевод публичных строк интерфейса; основные команды, терминология, обнаруженные ошибки и важные предупреждения выправлены вручную. Это не официальная и не полностью вычитанная человеком локализация. В редких экранах возможны неточности.

Счётчик в отчёте относится к распознаваемым конструкциям кода, **а не к проценту перевода всего приложения**. Тексты, собранные произвольным кодом, отдельные формы множественного числа, загружаемые с сервера сообщения, Marketplace, сторонние расширения, сообщения ОС и вывод CLI могут остаться английскими. Имена моделей, команд, файлов и проектов сохраняются там, где они являются данными.

Русификатор не переводит пользовательские документы, переписки, команды терминала, системные промпты агентов, сетевые протоколы и ключи данных. Язык ответов агента настраивается отдельно в Nimbalyst.

Файлы `SKILL.md`, команды Markdown и манифесты расширений сохраняются в оригинале. Их известные описания переводятся только при отображении. Произвольные сторонние и пользовательские навыки, отсутствующие в словаре, остаются на исходном языке; их можно добавить в `locales/custom.json`. Тексты не отправляются в сервисы перевода.

## Как это устроено

`lib/strings.cjs` разбирает JavaScript через Acorn и заменяет литералы только в заданных контекстах отображения: `children`, `label`, `title`, подсказки, диалоги, карты подписей и функции с явными именами для получения подписей. Сравнения, идентификаторы, ключи объектов и обычные значения `value`, `id`, `role` не переводятся. Нет наблюдателя DOM, подмены React, сетевого прокси или изменения настроек безопасности.

`lib/display.cjs` добавляет словарный перевод в конкретные места отображения описаний и подписей. Исходные объекты, обработчики нажатий, команды и запросы не меняются. `locales/skills.json` содержит описания навыков и расширений, а `locales/display.json` — динамические подписи интерфейса. Незнакомый текст возвращается без изменений.

`lib/asar.cjs` пересобирает `app.asar`, обновляет смещения и SHA-256 integrity, сохраняет метаданные и ссылки на распакованные файлы. После сборки все изменённые записи проверяются, а неизменённые сравниваются побайтно. Перед установкой JavaScript повторно разбирается парсером.

Запись проходит через проверенные временные файлы; при обычной ошибке замены уже изменённые файлы восстанавливаются. На случай аварийного завершения предусмотрен `Recover.cmd`. Работающий Nimbalyst блокирует установку, а не завершается принудительно.

## Исправление и расширение словаря

`locales/ru.json` — базовый словарь, `locales/manual.tsv` — ручные исправления, `locales/custom.json` — ваши переопределения с высшим приоритетом:

```json
{
  "Open Project": "Открыть проект",
  "Open {0}": "Открыть {0}"
}
```

Плейсхолдеры `{0}`, `{1}` и далее должны сохраниться без пропусков и повторов. После редактирования словаря выполните удаление и повторную установку мода. Исходники позволяют адаптировать распознавание новых конструкций приложения, а не заменять строки вслепую.

## Проверки разработчика

Сборка EXE из исходников на Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer/build.ps1
```

Скрипт скачивает закреплённую версию Node.js с официального сайта, проверяет SHA-256 архива и цифровую подпись OpenJS Foundation, затем компилирует C# стандартным компилятором .NET Framework. Результат — в `dist/`. Для сборки без повторной загрузки передайте `-NodeArchive <путь-к-архиву>`. Исходные компоненты закреплены, но побайтно воспроизводимая сборка не заявляется из-за временных меток ZIP и компилятора.

Проверка содержимого готового EXE без изменения Nimbalyst:

```powershell
$p = Start-Process .\dist\Nimbalyst-RU-Setup-1.2.0.exe -ArgumentList '--self-test "C:\Temp\Nimbalyst-RU-test"' -Wait -PassThru
$p.ExitCode
Get-Content C:\Temp\Nimbalyst-RU-test\self-test.log
```

```powershell
node --test .\tests\mod.test.cjs
node .\nimbalyst-ru.cjs diagnose
```

Тесты создают временные файлы только в `work` текущего каталога и имитируют проверку запущенного процесса. Они проверяют границы перевода, шаблоны, целостность ASAR, повторную установку, побайтный откат, отказ при несовместимости, отказ при работающем приложении, откат при ошибке и восстановление после прерывания. Полный перевод всех экранов этими тестами не подтверждается.

## Поиск готовых решений

На 11 ноября 2026 года готовый русский мод в выполненном поиске не найден. В [официальной FAQ](https://nimbalyst.com/docs/faqs/faqs/) указан английский язык интерфейса. Есть [обсуждение локализации №597](https://github.com/nimbalyst/nimbalyst/issues/597) и [форк с i18next и португальским переводом](https://github.com/ednilsonmarques/nimbalyst/tree/main/packages/runtime/src/i18n). Его подход был изучен, но это другая сборка приложения, а не устанавливаемый русский языковой пакет. Этот мод работает с установленной официальной сборкой и не заменяет её чужим форком.
