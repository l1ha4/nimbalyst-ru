# Проверка Nimbalyst RU 1.2.0

## Изменения 1.2.0

- 23 автоматизированных теста проходят: перевод строк и шаблонов, ASAR, установка и удаление, обновление старого мода, отказ при повреждённой резервной копии, откат ошибки и восстановление прерывания.
- Проверено отображение каждого из 187 описаний: русский результат, сохранение исходного объекта, идентификаторов команд, запросов и неизвестных пользовательских строк.
- Реальный архив Nimbalyst 0.83.0 пересобран из проверенных оригиналов. В нём найдены 20 точек перевода динамических описаний и подписей; функция из пересобранного архива проверена на всех 187 описаниях.
- Проверены заголовки групп без изменения ключей группировки, подписи быстрых действий без изменения отправляемого запроса, метаданные с переносами строк, даты с числовыми суффиксами имён функций.
- Проверены подсказки редактора, пустые состояния трекера, вложенные шаблоны навигации и атрибуты доступности; `data-*` и данные сообщений сохраняются.
- Пакет 1.2.0 подготовлен отдельно; установленная пользовательская программа в ходе этой доработки не изменялась. Все экраны визуально не проверены.

## Предыдущие проверки базового пакета 1.1.0

Дата: 11 ноября 2026 года. Приложение: Nimbalyst 0.83.0, Windows.

- 14 автоматизированных проверок установщика и преобразования кода — пройдены.
- Автономный EXE распакован и проверен через `--self-test`: все 14 тестов проходят на включённом Node.js 24.22.2, без использования установленного в системе Node.js.
- Графическое окно проверено на Windows: кнопки, подписи, запуск диагностики через PowerShell и обнаружение установленного мода работают. Отчёты сохраняются вне временной папки.
- Официальный архив Node.js проверен по SHA-256; цифровая подпись `node.exe` OpenJS Foundation действительна.
- Основная установка 0.83.0 проверена по хешам всех 24 изменённых файлов; резервные копии сохранены. Повторная установка через новый графический интерфейс поверх пользовательской программы не проводилась; преобразование и откат проверяются на тестовых пакетах.
- Проверена реальная сборка из установленного приложения: архив успешно пересобран и прочитан повторно; изменённый JavaScript проходит синтаксический разбор.
- Проверяются побайтное сохранение нетронутых записей ASAR и контрольные суммы файлов перед установкой и удалением.
- В проверенной тестовой сборке изменено 24 файла на диске: `app.asar` и файлы встроенных расширений. Внутри ASAR меняются только выбранные записи.
- Статический проход обнаружил примерно 10 тысяч переводимых вхождений. Этот показатель не означает, что каждый экран или серверное сообщение переведены полностью.
- Тестовая копия запущена с отдельным профилем. Визуально проверены главное окно, начальная настройка, меню «Файл», рабочее пространство и окно выбора разрешений.
- По замечанию пользователя исправлены все четыре названия режимов разрешений, их пояснения, подписи «Файлы» и «Действия».
- Повторная визуальная проверка последнего исправления блока разрешений была прервана пользователем; полного визуального аудита всех экранов нет.
- Код `PROJECT_TRUST_SETTINGS_BY_CHOICE`, определяющий поведение разрешений, сравнивался побайтно с оригиналом и не изменён.
- Проверены формы «1 файл», «2 файла», «5 файлов», «11 файлов», «21 файл» и перевод условных слов внутри шаблонов, например «Скрыть / Показать».

Не проверены все экраны приложения, реальные запуски ИИ-агентов, платные функции и сторонние расширения. Будущие версии требуют проверки совместимости. Основная масса редких фраз получена машинным переводом; часть словаря вычитана и исправлена вручную.

Для повторной проверки:

```powershell
node --test .\tests\mod.test.cjs
```

Рабочие отчёты создаются в `reports`. Отчёт о совместимости включает перечень обнаруженных непереведённых строк, а не тексты пользовательских документов.
